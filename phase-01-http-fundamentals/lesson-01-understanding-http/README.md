## Key Concepts

### HTTP
Hypertext Transfer Protocol. A communication protocol used for exchanging information between clients and servers.

### Client
An application that initiates a request.

Examples:
- Web browsers
- React applications
- Mobile applications
- Java applications

### Server
A system that receives requests, processes them and sends responses.

### Client-Server Communication

1. Client sends an HTTP request.
2. Server receives the request.
3. Server processes the request.
4. Server sends an HTTP response.

## HTTP Methods Introduced

| Method | Purpose |
|---|---|
| GET | Retrieve information |
| POST | Create information |
| PUT | Replace a resource |
| PATCH | Partially update a resource |
| DELETE | Delete a resource |
